# Suara bawaan bunyi huruf

Taruh di sini file bunyi huruf yang dipakai **semua perangkat**: `s.wav`, `a.wav`, `t.wav`, … (19 huruf, huruf kecil).

Cara termudah membuatnya:
1. Buka aplikasi → **👪 Orang tua** → rekam ke-19 bunyi (✅).
2. Buka **📦 Jadikan suara bawaan untuk semua perangkat**, lalu tekan **Ekspor**. File `sounds.zip` akan terunduh.
3. Ekstrak `sounds.zip`, lalu upload folder `sounds` ke repo (Add file → Upload files) di branch yang dipakai GitHub Pages.

Rekaman yang dibuat orang tua di perangkat sendiri (✅) tetap diutamakan daripada suara bawaan (📦).
