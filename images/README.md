# Folder gambar

Taruh ilustrasi di sini, dengan nama file yang **persis** sama seperti di `PROMPTS.md`:

```
images/b01/cover.png
images/b01/p1.png
images/b01/p2.png
...
images/b10/p6.png
```

- `.png`, `.jpg`, `.jpeg` dan `.webp` semuanya bisa.
- Ukuran ideal 1536×1024 (3:2). Perkecil file lebih dari ±500 KB (misalnya di squoosh.app).
- Selama gambar belum ada, aplikasi menampilkan emoji sementara, jadi aplikasinya tetap bisa dipakai.
